# Leave policy (this deployment only)

Files in this folder belong **only** to this Leave Manager instance.

- `annual-leave-policy.json` — machine-readable rules used by the app
- `Company Annual Leave Policy V3.docx` — human-readable policy document

Editing these files does **not** change `leave-manager-axon` or `axon-leave`. Each system keeps its own copy under its own `policy/` folder.
